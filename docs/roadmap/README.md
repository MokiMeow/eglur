# Eglur Roadmap

This directory contains non-normative design records for work beyond the v0.1
specification. These files may describe selected directions and candidate
requirements, but they do not define current language behavior or conformance.
A proposal becomes normative only after its contract moves into `docs/spec`, the
artifact inventory classifies it as normative, and the required conformance
evidence is defined.
