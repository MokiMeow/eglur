# Scope

Scope: Normative for v0.1 unless this file or a section states otherwise.

This document defines required diagnostic behavior for Eglur implementations, including:

1. Diagnostic object shape.
2. Required error/warning/note codes.
3. Required message content and metadata.
4. Deterministic ordering and rendering requirements used by conformance tests.
5. Code/channel compatibility rules (`code-channels.md`).

If `../SPEC.md` or `../STDLIB.md` requires a diagnostic and this document defines a code for that condition, conforming implementations MUST use the code defined here.
