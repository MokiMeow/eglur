# `std::str` (REQUIRED)

Scope: Normative for v0.1 unless this file or a section states otherwise.

String helpers are pure. No API in `std::str` is bang in v0.1.

`Str` is an immutable finite sequence of Unicode scalar values. Every `Str`
value therefore has a unique valid UTF-8 encoding; surrogate code points and
ill-formed host byte or code-unit sequences are not `Str` values. Boundary APIs
that cannot convert external data losslessly to that invariant MUST report
failure rather than inject replacement characters or escaped pseudo-text.

```eglur-catalog
opaque type FormatError
meta type FormatArg

fn Str.len_bytes(self: &Self) -> Nat
fn Str.is_empty(self: &Self) -> Bool

fn Str.contains(self: &Self, needle: &Str) -> Bool
fn Str.starts_with(self: &Self, prefix: &Str) -> Bool
fn Str.ends_with(self: &Self, suffix: &Str) -> Bool

fn Str.trim(self: &Self) -> Str
fn Str.trim_start(self: &Self) -> Str
fn Str.trim_end(self: &Self) -> Str

fn Str.replace(self: &Self, from: &Str, to: &Str) -> Str

fn Str.lines(self: &Self) -> Seq[Str]

fn Str.split(self: &Self, sep: &Str) -> Seq[Str]
fn Str.split_nonempty(self: &Self, sep: &Str) -> Seq[Str]

fn Str.strip_prefix(self: &Self, prefix: &Str) -> Opt[Str]
fn Str.strip_suffix(self: &Self, suffix: &Str) -> Opt[Str]

fn Str.to_lower_ascii(self: &Self) -> Str
fn Str.to_upper_ascii(self: &Self) -> Str

fn concat(parts: Seq[Str]) -> Str
fn format(template: Str, args: named FormatArg...) -> Res[Str, FormatError]
```

The [canonical lexical text order](../language/invariants.md#canonical-lexical-text-order)
is shared by baseline language and standard-library contracts that require a
deterministic text order. It does not add a source-level comparison API or make
`Str` implement `Ord` in v0.1.

Semantics:

1. All operations above MUST be deterministic.
2. `lines` splits text into logical lines using text-line semantics:
   1. line terminators are `\n` and `\r\n`,
   2. returned line values exclude the consumed terminator,
   3. a terminal line terminator does not produce an additional trailing empty line,
   4. empty input yields an empty sequence.
3. `split` tokenization is left-to-right on non-overlapping separator matches.
4. `split` MUST preserve empty tokens generated by:
   1. adjacent separators,
   2. a leading separator,
   3. a trailing separator.
5. `split_nonempty` MUST be equivalent to `split(...).filter { !_.is_empty() }`.
6. If `sep` is empty (`""`), `split` and `split_nonempty` MUST return a single-element sequence containing the original string unchanged.
7. `replace` MUST replace all non-overlapping matches in left-to-right order.
8. If `from` is empty (`""`), `replace` MUST return the original string unchanged.
9. `strip_prefix`:
   1. returns `Some(rest)` when `self` starts with `prefix`,
   2. returns `None` otherwise,
   3. empty prefix matches and returns `Some(self)`.
10. `strip_suffix`:
   1. returns `Some(rest)` when `self` ends with `suffix`,
   2. returns `None` otherwise,
   3. empty suffix matches and returns `Some(self)`.
11. `trim`, `trim_start`, and `trim_end` remove only ASCII whitespace in v0.1:
   1. space (`U+0020`),
   2. horizontal tab (`U+0009`),
   3. line feed (`U+000A`),
   4. carriage return (`U+000D`),
   5. vertical tab (`U+000B`),
   6. form feed (`U+000C`).
12. `to_lower_ascii` and `to_upper_ascii` transform only ASCII letters; non-ASCII code points MUST remain unchanged.
13. `concat` preserves input part order exactly.
14. `format` placeholder grammar in v0.1 is named-only:
    1. `{name}` uses the same `Display.to_str` implementation selected by the fully qualified trait call and the prelude `to_str(value)` adapter,
    2. `{name:?}` uses `Debug` formatting.
15. `format` call arguments are named arguments (`format("x={x}", x=value)`).
16. Literal braces in `format` templates MUST be escaped as `{{` and `}}`.
17. `format` MUST return `Err(FormatError)` on placeholder/argument mismatch, including:
    1. missing placeholder binding,
    2. extra named argument with no corresponding placeholder,
    3. invalid placeholder grammar,
    4. unmatched literal `{` or `}`.
18. Repeated placeholder names are valid and MUST reuse the same bound argument value.
19. `FormatArg` is a catalog-only named-argument family. Each captured value MUST satisfy `Display` for a `{name}` placeholder or `Debug` for a `{name:?}` placeholder.
20. `format` MUST NOT select a module-local formatting overload or a representation that differs from the applicable prelude trait contract.
