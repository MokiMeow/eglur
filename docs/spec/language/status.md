# Document Status

Scope: Normative for v0.1 unless this file or a section states otherwise.

The v0.1 specification defines the Eglur language, including its bounded
first-class tensor source layer.

This is a working draft targeting Eglur 0.1.0, not a separately released
specification. A Git commit identifies a particular draft; publication of the
repository does not freeze the language. The specification and implementation
will be versioned together at the eventual Eglur release.

Unless a section explicitly states otherwise, statements in the indexed
language specification are normative.

Items in the [language OPEN source](../open-items/language.md) are unresolved
release-control records and do not add v0.1.0 conformance requirements.
