# Specification Requirement Style

This contributor guide is informative. It standardizes wording for authors but
does not itself define language or library behavior.

Use the following sentence patterns for new clauses:

1. Requirement: `X MUST Y under condition Z.`
2. Prohibition: `X MUST NOT Y under condition Z.`
3. Recommendation: `X SHOULD Y when condition Z holds.`
4. Optional feature: `X MAY Y; if provided, it MUST satisfy Z.`
